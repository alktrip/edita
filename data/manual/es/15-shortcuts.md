# Atajos de teclado

Estos son los atajos de las órdenes de los menús, tal como están ahora: si cambias uno en
{{actionShortcutMapper}}, esta página muestra el nuevo. Las órdenes sin atajo se pueden ejecutar
desde la [paleta de órdenes](05-views.md#paleta-de-ordenes) ({{key:actionCommandPalette}}), o puedes
asignarles uno.

En macOS, Ctrl es la tecla Comando (⌘).
{{shortcuts}}

## Teclas del editor

Estas teclas son del propio editor (se cambian en la pestaña **Órdenes de Scintilla** de la
Asignación de atajos):

| Teclas | Acción |
|---|---|
| Ctrl+Izquierda / Ctrl+Derecha | Palabra anterior / siguiente |
| Inicio / Fin | Principio / final de la línea |
| Ctrl+Inicio / Ctrl+Fin | Principio / final del documento |
| Ctrl+Arriba / Ctrl+Abajo | Desplazar una línea sin mover el cursor |
| Mayús+flechas, Mayús+Inicio, Mayús+Fin… | Seleccionar al moverse |
| Alt+Mayús+flechas | Selección rectangular |
| Ctrl+Retroceso / Ctrl+Supr | Borrar la palabra anterior / siguiente |
| Ctrl+Mayús+Retroceso / Ctrl+Mayús+Supr | Borrar hasta el principio / el final de la línea |
| Ctrl+L | Cortar la línea |
| Ctrl+Mayús+X | Copiar la línea |
| Ctrl+Mayús+L | Borrar la línea |
| Ctrl+T | Intercambiar la línea con la anterior |
| Tab / Mayús+Tab | Aumentar / reducir la sangría de las líneas seleccionadas (o ir al hueco siguiente / anterior de un fragmento) |
| Insert | Insertar o sobrescribir |
| Esc | Volver a un solo cursor; cierra listas y barras |

## Otras teclas

| Dónde | Teclas | Acción |
|---|---|---|
| Ratón | Ctrl+clic | Añadir un cursor |
| Ratón | Alt+arrastrar | Selección rectangular |
| Ratón | Ctrl+rueda | Zoom |
| Pestañas | Clic central | Cerrar la pestaña |
| Barra de búsqueda | Intro / Mayús+Intro | Coincidencia siguiente / anterior |
| Barra de búsqueda | Alt+C, Alt+W, Alt+R | Mayúsculas, palabra completa, expresión regular |
| Barra de búsqueda | Ctrl+Alt+Intro | Reemplazar todas |
| Terminal | Ctrl+Mayús+C / Ctrl+Mayús+V | Copiar / pegar |
| Terminal | Mayús+RePág / Mayús+AvPág | Recorrer el historial |
| Manual | Alt+Izquierda / Alt+Derecha | Atrás / adelante |
| Manual | Ctrl+F | Buscar en el manual |
