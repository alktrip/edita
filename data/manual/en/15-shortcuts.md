# Keyboard shortcuts

These are the shortcuts of the menu commands, as they are now: if you change one in
{{actionShortcutMapper}}, this page shows the new one. The commands without a shortcut can be run
from the [command palette](05-views.md#command-palette) ({{key:actionCommandPalette}}), or you can
give them one.

On macOS, Ctrl is the Command key (⌘).
{{shortcuts}}

## Editor keys

These keys belong to the editor itself (they can be changed in the **Scintilla commands** tab of the
Shortcut Mapper):

| Keys | Action |
|---|---|
| Ctrl+Left / Ctrl+Right | Previous / next word |
| Home / End | Start / end of the line |
| Ctrl+Home / Ctrl+End | Start / end of the document |
| Ctrl+Up / Ctrl+Down | Scroll one line without moving the cursor |
| Shift+arrows, Shift+Home, Shift+End… | Select while moving |
| Alt+Shift+arrows | Rectangular selection |
| Ctrl+Backspace / Ctrl+Delete | Delete the previous / next word |
| Ctrl+Shift+Backspace / Ctrl+Shift+Delete | Delete to the start / end of the line |
| Ctrl+L | Cut the line |
| Ctrl+Shift+X | Copy the line |
| Ctrl+Shift+L | Delete the line |
| Ctrl+T | Swap the line with the previous one |
| Tab / Shift+Tab | Indent / unindent the selected lines (or go to the next / previous gap of a snippet) |
| Insert | Insert or overwrite |
| Esc | Back to a single cursor; closes lists and bars |

## Other keys

| Where | Keys | Action |
|---|---|---|
| Mouse | Ctrl+click | Add a cursor |
| Mouse | Alt+drag | Rectangular selection |
| Mouse | Ctrl+wheel | Zoom |
| Tabs | Middle click | Close the tab |
| Find bar | Enter / Shift+Enter | Next / previous match |
| Find bar | Alt+C, Alt+W, Alt+R | Match case, whole word, regular expression |
| Find bar | Ctrl+Alt+Enter | Replace all |
| Terminal | Ctrl+Shift+C / Ctrl+Shift+V | Copy / paste |
| Terminal | Shift+PgUp / Shift+PgDown | Scroll the history |
| Manual | Alt+Left / Alt+Right | Back / forward |
| Manual | Ctrl+F | Search the manual |
