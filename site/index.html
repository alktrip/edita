A Notepad++-style editor,
built for Linux

Edita keeps the menus, shortcuts, search modes, macros, sessions, themes and configuration files you know from Notepad++, on the same editing engine, with Notepad++ plugins ported from their source code. And it adds what a developer expects today: language servers, Git and a terminal.

Everything you use in Notepad++

Edita is built on Scintilla and Lexilla, like Notepad++, and reads the same langs.xml, stylers.xml, shortcuts.xml and session files, so you can bring your configuration with you.

Find and replace

Normal, extended and regular expressions, in files and folders, with Mark, bookmarks and the search results panel.

Macros and multi-editing

Record, save and run macros; column editor, multiple carets, hide lines and folding.

Tabs, views and sessions

Two views and clones, pinned tabs, named sessions and session restore, as you left them.

95 languages, 30 themes

User Defined Languages and the Style Configurator, all in Notepad++ formats.

Panels

Document Map, Function List, Folder as Workspace, Clipboard History and Character Panel.

Encodings

Encoding and line-ending detection like Notepad++, with more than 40 character sets.

And what a developer expects today

Without becoming a full IDE: Edita stays a fast, native editor.

Language servers (LSP)

Diagnostics, completion, hover, go to definition, references, rename, formatting, code actions and inlay hints.

Git

Changes in the margin, stage or revert a single block, a commit panel, history and blame.

Integrated terminal

Terminals in tabs below the editor, with your shell.

Project tasks

Make, CMake, npm, Cargo, Go, pytest, Meson and just, with clickable errors.

Command palette

Every command, go to file and go to symbol, a few keystrokes away.

Compare and local history

Compare two files, or a file with its saved or Git version; every saved version is kept.

CSV, JSON and YAML

Colored columns, align and sort; validate, format and convert, and copy the path at the caret.

Secret scanner

API keys and passwords are underlined as you type, and a commit with one asks first.

Built-in manual

F1 opens the section of the dialog or panel you are in, in English or Spanish.

Notepad++ plugins, on Linux

Edita speaks the Notepad++ plugin API. Plugins written for Windows are compiled for Linux with Edita's compatibility layer and published in a signed catalog, for x86_64 and arm64. Install them from Plugins › Plugins Admin.

From the Notepad++ world

XML Tools, JSON Viewer, MIME Tools, Npp Converter, Elastic Tabstops, Format SQL and more.

Included with Edita

Python Script, MarkdownViewer++, a hex editor and the secret scanner.

For plugin authors

A documented C API compatible with Notepad++ messages, an SDK and a toolchain to port existing plugins.

Questions

Is Edita Notepad++?

No. Edita is an independent project, derived from Notepad++ under the GNU GPL v3. It is not affiliated with or endorsed by Don Ho or the Notepad++ project. It is a Linux application written in C++ with Qt that follows the Notepad++ workflow and is compatible with its configuration files and its plugin API. Notepad++ is a trademark of its owner.

Why not run Notepad++ with Wine?

Wine works, but the result does not feel like a Linux application: fonts, scaling, file dialogs, Wayland and the clipboard behave differently, and plugins that touch the system often fail. Edita is native: it uses your desktop's look, your files and your tools.

Can I bring my Notepad++ settings?

Yes. Edita uses the same files (config.xml, langs.xml, stylers.xml, shortcuts.xml, themes and user defined languages) in ~/.config/edita/.

Will it run my Notepad++ plugins?

Notepad++ plugins are Windows programs, so they have to be compiled for Linux. Edita's compatibility layer makes that possible without rewriting them, and the signed catalog already has the ones that build. Plugin authors can port theirs with the SDK.

How do I report a problem?

Help › Report a Problem opens a GitHub issue with your version and system filled in. You can also open one directly.
