El flujo de trabajo de Notepad++,
nativo en Linux

Edita conserva los menús, atajos, modos de búsqueda, macros, sesiones, temas y archivos de configuración que conoces de Notepad++, sobre el mismo motor de edición. También ejecuta plugins de Notepad++. Y añade lo que hoy espera quien programa: servidores de lenguaje, Git y una terminal.

Preguntas

¿Edita es Notepad++?

No. Edita es un proyecto independiente, sin relación con Notepad++. Es un programa nuevo para Linux, escrito en C++ con Qt, que sigue el flujo de trabajo de Notepad++ y es compatible con sus archivos de configuración y su API de plugins. Notepad++ es una marca de sus dueños.

¿Por qué no usar Notepad++ con Wine?

Wine funciona, pero el resultado no se siente como una aplicación de Linux: las fuentes, la escala, los diálogos de archivos, Wayland y el portapapeles se comportan distinto, y los plugins que tocan el sistema a menudo fallan. Edita es nativa: usa el aspecto de tu escritorio, tus archivos y tus herramientas.

¿Puedo traer mi configuración de Notepad++?

Sí. Edita usa los mismos archivos (config.xml, langs.xml, stylers.xml, shortcuts.xml, temas y lenguajes definidos por el usuario) en ~/.config/edita/.

¿Funcionarán mis plugins de Notepad++?

Los plugins de Notepad++ son programas de Windows, así que hay que compilarlos para Linux. La capa de compatibilidad de Edita lo hace posible sin reescribirlos, y el catálogo firmado ya tiene los que compilan. Quien escribe plugins puede portar los suyos con el SDK.

¿Cómo reporto un problema?

Ayuda › Reportar un problema abre un issue en GitHub con tu versión y tu sistema ya escritos. También puedes abrirlo directamente.
