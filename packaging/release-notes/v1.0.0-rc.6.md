**Edita 1.0.0 rc 6**, la sexta versión candidata a la 1.0. Corrige fallos encontrados al revisar el código después de la rc 5, entre ellos otro caso que podía dejar la ventana en negro. Si usas la rc 5, actualiza.

*The sixth release candidate of Edita 1.0. It fixes bugs found in a code review after rc 5, including another case that could leave the window black. If you use rc 5, please update. English below.*

## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.6_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0.rc.6-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-rc.6-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si ya tenías una versión anterior, instala esta encima: tu configuración se conserva.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux.

## Qué cambia desde la rc 5

- **Otro caso de la ventana en negro.** Un plugin puede poner cualquier texto en la barra de estado, y el nombre de un lenguaje definido por el usuario o de una tarea también puede ser largo. Con un texto de miles de caracteres, la barra pedía todo ese ancho a la ventana, igual que la ruta de navegación en la rc 4. Ahora cada campo de la barra muestra hasta 80 caracteres y se recorta si la ventana es estrecha; el estado del panel de tareas, igual.
- **Un commit con hooks lentos ya no se cancela.** El commit del panel Git esperaba con la ventana parada y se cancelaba a los 30 segundos: un hook pre-commit lento (linters, pruebas) o una firma GPG esperando la frase de paso lo abortaban. Ahora la ventana sigue respondiendo, sin límite de tiempo; si el hook falla, el aviso muestra lo que dijo y el mensaje se conserva.
- **El historial de Git no para la ventana.** En un repositorio grande, el historial del archivo actual tardaba segundos al cambiar de documento.
- **Guardar por una cadena de enlaces simbólicos** (a → b → archivo) escribía en `b` y lo convertía en un archivo normal. Ahora llega al archivo real.
- **Menos memoria al formatear.** Aplicar un formateador externo a un archivo grande en el que cambian todas las líneas podía usar 1.5 GB; ahora, como mucho unos 100 MB.
- **Panel TODO con documentos grandes**: en uno de decenas de MB, escribir ya no se traba; la búsqueda va en segundo plano.

Lo nuevo de la rc 4 (CSV, JSON y YAML, panel TODO, historial de Git, filtro de carpetas, F1 contextual, Acerca de, plugins para arm64) está en sus [notas](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).

## What changes since rc 5

- **Another case of the black window.** A plugin can put any text in the status bar, and the name of a user-defined language or of a task can also be long. With a text thousands of characters long, the status bar asked the window for all that width, like the breadcrumbs in rc 4. Now each status bar field shows up to 80 characters and is cut when the window is narrow; the task panel status too.
- **A commit with slow hooks is no longer cancelled.** The Git panel commit waited with the window frozen and was cancelled after 30 seconds: a slow pre-commit hook (linters, tests) or a GPG signature waiting for the passphrase aborted it. Now the window stays responsive, with no time limit; if the hook fails, the warning shows what it said and the message is kept.
- **The Git history no longer freezes the window.** In a large repository, the history of the current file took seconds when switching documents.
- **Saving through a chain of symbolic links** (a → b → file) wrote to `b` and turned it into a regular file. Now it reaches the real file.
- **Less memory when formatting.** Applying an external formatter to a large file where every line changes could use 1.5 GB; now at most about 100 MB.
- **TODO panel with large documents**: in one of tens of MB, typing no longer stutters; the search runs in the background.

What is new in rc 4 (CSV, JSON and YAML, TODO panel, Git history, folder filter, contextual F1, About, arm64 plugins) is in its [notes](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).
