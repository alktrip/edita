**Edita 0.9.0 beta 1**: la primera beta pública. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The first public beta of Edita, a native text editor for Linux inspired by Notepad++. English below.*

## Descargar

`Edita-0.9.0-beta.1-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Trae Qt, Python Script y MarkdownViewer++.

## Qué hay

- Casi todo Notepad++: pestañas y dos vistas, buscar y reemplazar (también en archivos), macros, edición en columna, sesiones, plegado, mapa del documento, lista de funciones, lenguajes definidos por el usuario, temas y el Configurador de estilos, el menú Ejecutar, la asignación de atajos…
- Lo que Notepad++ no tiene: paleta de órdenes (Ctrl+Mayús+A), Git en el margen y blame, terminal integrada, servidores de lenguaje (LSP), comparar archivos, fragmentos, probador de expresiones regulares, manual integrado (F1) en español e inglés.
- **Plugins de Notepad++** compilados para Linux desde su código original: 17 en el catálogo firmado (Plugins › Administrador de plugins), entre ellos XML Tools, MIME Tools y un formateador de SQL. Los DLL de Windows no funcionan en Linux.

## Es una beta

Úsala para trabajar, pero guarda copias de lo importante. Para reportar un problema: **Ayuda › Reportar un problema…**, que abre el formulario con tu versión y tu sistema. La guía [PROBAR.md](https://github.com/alktrip/edita/blob/main/PROBAR.md) dice qué probar.

## Download

`Edita-0.9.0-beta.1-x86_64.AppImage`, for Linux x86_64: Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. Make it executable (`chmod +x`) and open it. It includes Qt, Python Script and MarkdownViewer++.

## What is in it

- Most of Notepad++: tabs and two views, find and replace (also in files), macros, column editing, sessions, folding, document map, function list, user-defined languages, themes and the Style Configurator, the Run menu, the Shortcut Mapper…
- What Notepad++ does not have: a command palette (Ctrl+Shift+A), Git in the margin and blame, an integrated terminal, language servers (LSP), file comparison, snippets, a regular expression tester, a built-in manual (F1) in English and Spanish.
- **Notepad++ plugins** compiled for Linux from their original source code: 17 in the signed catalog (Plugins › Plugins Admin), including XML Tools, MIME Tools and a SQL formatter. Windows DLLs do not work on Linux.

## It is a beta

Use it for your work, but keep copies of what matters. To report a problem: **Help › Report a Problem…**, which opens the form with your version and your system. The [testing guide](https://github.com/alktrip/edita/blob/main/PROBAR.md#testing-edita-090-beta) says what to test.
