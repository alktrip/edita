**Edita 0.9.0 beta 9**, la novena beta pública. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The ninth public beta of Edita, a native text editor for Linux inspired by Notepad++. English below.*

> **macOS:** la versión para macOS se retomará cuando haya una versión estable para Linux. Esta beta es solo para Linux.

## Descargar

- `Edita-0.9.0-beta.9-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Si ya tenías una beta anterior, solo sustitúyela: tu configuración se conserva.
- **Nuevo:** `edita_0.9.0~beta.9_amd64.deb`, para Debian 12 y Ubuntu 22.04 o más nuevo: `sudo apt install ./edita_*_amd64.deb`. Deja Edita en el menú, en **Abrir con** y en la terminal (`edita`). Lleva su propio Qt, como el AppImage.

## Qué cambia desde la beta 8

- **Asociación de archivos:** **Configuración › Preferencias › Asociación de archivos**, como en Notepad++. Elige las extensiones que quieres abrir con Edita desde el administrador de archivos. En Linux se asocia el tipo de archivo, así que al asociar `.cpp` también se abren con Edita los `.cc`. Al quitar la asociación vuelve el programa que había antes. No hace falta ser administrador.
- **Con el AppImage**, al asociar una extensión Edita se añade al menú del escritorio. Si después mueves el AppImage o lo cambias por otra versión, Edita corrige la ruta al abrirse.
- **El paquete .deb** para Debian y Ubuntu (ver arriba).

Lo nuevo de las betas anteriores está en las notas de la [beta 8](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.8) y de la [beta 7](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.7).

## Es una beta

## Download

- `Edita-0.9.0-beta.9-x86_64.AppImage`, for Linux x86_64: Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. Make it executable (`chmod +x`) and open it. If you had an earlier beta, just replace it: your settings are kept.
- **New:** `edita_0.9.0~beta.9_amd64.deb`, for Debian 12 and Ubuntu 22.04 or newer: `sudo apt install ./edita_*_amd64.deb`. It puts Edita in the menu, in **Open With** and in the terminal (`edita`). It includes its own Qt, like the AppImage.

## What changes since beta 8

- **File association:** **Settings › Preferences › File Association**, as in Notepad++. Choose the extensions that the file manager opens with Edita. On Linux a file type is associated, so associating `.cpp` also opens `.cc` files with Edita. Removing the association gives the type back to the application it had before. You do not need to be an administrator.
- **With the AppImage**, associating an extension adds Edita to the desktop menu. If you later move the AppImage or replace it with another version, Edita fixes the path when it starts.
- **The .deb package** for Debian and Ubuntu (see above).

What is new in earlier betas is in the notes of [beta 8](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.8) and [beta 7](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.7).
