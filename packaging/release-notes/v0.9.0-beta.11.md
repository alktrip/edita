**Edita 0.9.0 beta 11**, la undécima beta pública. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The eleventh public beta of Edita, a native text editor for Linux inspired by Notepad++. English below.*

> **macOS:** la versión para macOS se retomará cuando haya una versión estable para Linux. Esta beta es solo para Linux.

## Descargar

- `Edita-0.9.0-beta.11-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Si ya tenías una beta anterior, solo sustitúyela: tu configuración se conserva.
- `edita_0.9.0.beta.11_amd64.deb`, para Debian 12 y Ubuntu 22.04 o más nuevo: `sudo apt install ./edita_*_amd64.deb`.

## Qué cambia desde la beta 10

Edita se pone al día con **Notepad++ 8.9.9**:

- **Buscar: resaltar mientras escribes.** Una casilla nueva a la derecha de «Buscar» marca en el documento todo lo que coincide con la búsqueda mientras el diálogo está abierto. Viene apagada. El color es el del estilo «Find matches highlight all» (antes «Incremental highlight all»).
- **Reemplazar sin avanzar.** Otra casilla, junto al botón **Reemplazar**, hace que después de reemplazar el cursor se quede ahí en lugar de saltar a la siguiente aparición.
- **Scintilla 5.6.9 y Lexilla 5.5.5**, con arreglos en el coloreado de HTML, Perl, C++, SQL, YAML y Markdown.
- **Lista de funciones:** en Bash ya no se pierden las funciones que siguen a una línea con solo `#`. En INI y PowerShell se aceptan nombres con `+`.
- **R:** se colorean las secuencias de escape dentro de las cadenas.
- **Espacios visibles:** los puntos crecen con el zoom.
- **Historial del portapapeles:** ya no corta un emoji por la mitad.

Nos interesa sobre todo cómo te va con las dos casillas nuevas del diálogo de búsqueda. Lo nuevo de las betas anteriores está en las notas de la [beta 10](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.10) y de la [beta 9](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.9).

## What changes since beta 10

Edita catches up with **Notepad++ 8.9.9**:

- **Find: highlight while typing.** A new checkbox to the right of "Find what" marks everything in the document that matches the search while the dialog is open. It is off by default. The colour comes from the "Find matches highlight all" style (formerly "Incremental highlight all").
- **Replace without moving on.** Another checkbox, next to the **Replace** button, keeps the cursor where it is after replacing instead of jumping to the next occurrence.
- **Scintilla 5.6.9 and Lexilla 5.5.5**, with colouring fixes for HTML, Perl, C++, SQL, YAML and Markdown.
- **Function List:** in Bash, functions after a line with only `#` are no longer lost. INI and PowerShell accept names with `+`.
- **R:** escape sequences inside strings are coloured.
- **Visible whitespace:** the dots grow with the zoom.
- **Clipboard history** no longer cuts an emoji in half.

We would especially like to hear how the two new checkboxes in the Find dialog work for you. What is new in earlier betas is in the notes of [beta 10](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.10) and [beta 9](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.9).
