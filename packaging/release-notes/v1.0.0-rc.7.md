**Edita 1.0.0 rc 7**, la séptima versión candidata a la 1.0. Se pone al día con los últimos cambios de Notepad++ (8.9.9.1 y las correcciones de noviembre) y corrige dos fallos que Edita compartía con Notepad++.

*The seventh release candidate of Edita 1.0. It catches up with the latest Notepad++ changes (8.9.9.1 and the November fixes) and fixes two bugs Edita shared with Notepad++. English below.*

## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.7_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0.rc.7-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-rc.7-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si ya tenías una versión anterior, instala esta encima: tu configuración se conserva.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux.

## Qué cambia desde la rc 6

- **Recortar espacios sin perder el sitio.** Recortar los espacios de una selección (y también ordenar líneas o convertir tabuladores) movía la vista hasta el final de la selección y dejaba el cursor abajo. Ahora la vista y la selección quedan como estaban. Notepad++ corrigió lo mismo este mes.
- **Ordenar las pestañas respeta las fijadas.** Ventana › Ordenar por y el botón Ordenar del diálogo Ventanas podían poner una pestaña fijada detrás de las demás. Ahora las fijadas siguen al principio, ordenadas entre ellas.
- **Color para los literales de usuario de C++** (`10_km`, `1.5_kg`), en todos los temas, como en Notepad++.
- **Los estilos nuevos llegan a quien ya usaba Edita.** Hasta ahora, los colores de los lenguajes se copiaban a tu configuración la primera vez y no se ponían al día. Ahora, al actualizar Edita, tu `stylers.xml` y los temas que modificaste reciben los estilos nuevos sin perder tus cambios, como hace Notepad++.

Lo que trajeron la rc 6 (correcciones de la revisión del código) y la rc 4 (CSV, JSON y YAML, panel TODO, historial de Git y más) está en sus notas: [rc 6](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.6), [rc 4](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).

## Download

There are builds for PCs (**x86_64**) and for 64-bit ARM (**arm64**: Raspberry Pi 4 and 5, ARM laptops and servers). `uname -m` tells which one your computer is.

| System | File | Install |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.7_amd64.deb` or `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE and compatible | `edita-1.0.0.rc.7-1.x86_64.rpm` or `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` or `sudo zypper install ./edita-*.rpm` |
| Any other distribution | `Edita-1.0.0-rc.7-x86_64.AppImage` or `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` and open it |

On x86_64 it works on Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. On arm64 it needs Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 or newer. If you had an earlier version, install this one over it: your settings are kept.

> **macOS:** the macOS version will resume after 1.0 for Linux.

## What changes since rc 6

- **Trimming spaces keeps your place.** Trimming the spaces of a selection (and also sorting lines or converting tabs) scrolled the view to the end of the selection and left the caret at the bottom. Now the view and the selection stay as they were. Notepad++ fixed the same thing this month.
- **Sorting tabs respects pinned tabs.** Window › Sort By and the Sort button of the Windows dialog could put a pinned tab behind the others. Now pinned tabs stay first, sorted among themselves.
- **A color for C++ user-defined literals** (`10_km`, `1.5_kg`), in every theme, as in Notepad++.
- **New styles reach existing users.** Until now, language colors were copied to your settings the first time and never updated. Now, when you update Edita, your `stylers.xml` and the themes you modified get the new styles without losing your changes, as Notepad++ does.

What rc 6 (fixes from the code review) and rc 4 (CSV, JSON and YAML, TODO panel, Git history and more) brought is in their notes: [rc 6](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.6), [rc 4](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).
