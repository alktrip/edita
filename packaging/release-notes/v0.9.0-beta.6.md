**Edita 0.9.0 beta 6**, la sexta beta pública. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The sixth public beta of Edita, a native text editor for Linux inspired by Notepad++. English below.*

> **macOS:** la versión para macOS todavía no está lista, por limitaciones en el desarrollo. Esta beta es solo para Linux.

## Descargar

`Edita-0.9.0-beta.6-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Si ya tenías una beta anterior, solo sustitúyela: tu configuración se conserva.

## Qué hay de nuevo desde la beta 5

- **Corregido en Ubuntu 26.10:**
  - el AppImage ya no pide `libOpenGL.so.0` (no arrancaba sin el paquete `libopengl0`);
  - XML Tools del catálogo lleva su libxml2 dentro y carga también donde la del sistema es más nueva. Si lo tenías instalado, desinstálalo y vuelve a instalarlo desde el administrador de plugins.
- **Dar formato al documento** (Alt+Mayús+F) con la herramienta de cada lenguaje, si está instalada: `clang-format`, `prettier`, `ruff` o `black`, `rustfmt`, `gofmt`, `shfmt`, `xmllint`… Si no hay, el servidor de lenguaje. Solo cambian las líneas que la herramienta cambió, y se puede hacer al guardar (**Preferencias › Formato**).
- **Corrector ortográfico:** las palabras mal escritas se subrayan en rojo (en el código, solo en comentarios y cadenas); con el clic derecho, sugerencias, añadir al diccionario o pasar por alto. Usa los diccionarios del sistema: para español e inglés, `sudo apt install hunspell-es hunspell-en-us`.
- **Enlaces:** las direcciones web quedan subrayadas y se abren con doble clic.
- **El menú del clic derecho** es el de Notepad++, y se personaliza en **Configuración › Editar el menú contextual** (`contextMenu.xml`).
- **Archivo:** renombrar, mover a la papelera, abrir con la aplicación predeterminada, abrir la carpeta contenedora en el administrador de archivos o en la terminal.
- **Editar:**
  - **Sobre la selección:** abrir la ruta seleccionada, taparla con █, buscarla en internet;
  - panel de caracteres e historial del portapapeles;
  - sangría desde el menú, marcar inicio y fin de una selección larga, solo lectura para todos;
  - **Ctrl+doble clic** selecciona lo que hay entre paréntesis.
- **Buscar › Buscar caracteres en un rango** (por ejemplo, los que no son ASCII).
- **Ver:** mostrar los caracteres no imprimibles (NBSP, ZWSP…).
- **Configuración › Importar** plugins y temas desde un archivo; **Macro › Modificar atajo/Borrar macro**.
- **Preferencias nuevas:** Barra de herramientas, Lenguaje (menú compacto, lenguajes ocultos), Delimitadores, Rendimiento (archivos grandes), Nube y enlaces (la configuración en una carpeta sincronizada), Buscador, Formato y Ortografía.

## Es una beta

## Download

`Edita-0.9.0-beta.6-x86_64.AppImage`, for Linux x86_64: Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. Make it executable (`chmod +x`) and open it. If you had an earlier beta, just replace it: your settings are kept.

## What is new since beta 5

- **Fixed on Ubuntu 26.10:**
  - the AppImage no longer needs `libOpenGL.so.0` (it did not start without the `libopengl0` package);
  - XML Tools from the catalog carries its own libxml2 and also loads where the system one is newer. If you had it installed, uninstall it and install it again from the Plugins Admin.
- **Format Document** (Alt+Shift+F) with the tool of each language, if it is installed: `clang-format`, `prettier`, `ruff` or `black`, `rustfmt`, `gofmt`, `shfmt`, `xmllint`… If there is none, the language server. Only the lines the tool changed are changed, and it can be done on save (**Preferences › Formatting**).
- **Spell checker:** misspelled words are underlined in red (in code, only in comments and strings); right-click for suggestions, add to the dictionary or ignore. It uses the dictionaries of the system: for Spanish and English, `sudo apt install hunspell-es hunspell-en-us`.
- **Links:** web addresses are underlined and open with a double click.
- **The right-click menu** is the one of Notepad++, and it is customized in **Settings › Edit Popup ContextMenu** (`contextMenu.xml`).
- **File:** rename, move to trash, open in the default viewer, open the containing folder in the file manager or in the terminal.
- **Edit:**
  - **On Selection:** open the selected path, redact it with █, search it on the internet;
  - character panel and clipboard history;
  - indent from the menu, begin/end select for long selections, read-only for all documents;
  - **Ctrl+double click** selects what is between parentheses.
- **Search › Find Characters in Range** (for example, the non-ASCII ones).
- **View:** show non-printing characters (NBSP, ZWSP…).
- **Settings › Import** plugins and themes from a file; **Macro › Modify Shortcut/Delete Macro**.
- **New preferences:** Toolbar, Language (compact menu, hidden languages), Delimiter, Performance (large files), Cloud and Link (the settings in a synchronized folder), Search Engine, Formatting and Spelling.

## It is a beta

Use it for your work, but keep copies of what matters. To report a problem: **Help › Report a Problem…**. The [testing guide](https://github.com/alktrip/edita/blob/main/PROBAR.md#testing-edita-090-beta) says what to test.
