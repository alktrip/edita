## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.8_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0.rc.8-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-rc.8-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si ya tenías una versión anterior, instala esta encima: tu configuración se conserva.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux.

## Qué cambia desde la rc 7

- **Ajuste de línea por documento**, como la próxima versión de Notepad++: Ver › Ajuste de línea cambia el del documento actual (en las dos vistas si está clonado), la sesión lo guarda y la preferencia pasa a ser la de los documentos nuevos. Un archivo grande se abre sin ajuste sin quitárselo a los demás.
- **La lista de funciones de Bash** ya no se pierde después de un here-document con el delimitador entre comillas (`<<'EOF'`, `<<"EOF"`).
- **Un icono para los documentos en seguimiento** (Ver › Seguimiento), el mismo en las pestañas, la Lista de documentos y la paleta.
- **El tema Deep Black**, al día con el de Notepad++.
- **Edita en las tiendas de Linux**: con sus metadatos de AppStream, Edita instalada desde el .deb o el .rpm aparece en GNOME Software y KDE Discover con su descripción y sus capturas.
- **Lista para Flatpak**: dentro de Flatpak, git, los servidores de lenguaje, las tareas y la terminal usan los programas de tu sistema. El paquete de Flathub llegará con la 1.0.
- **Sitio web**: https://alktrip.github.io/edita/es/
- **Textos más claros** sobre qué es Edita y su relación con Notepad++, en la aplicación (Ayuda › Acerca de Edita), el README y la tienda.

| System | File | Install |

| Fedora, openSUSE and compatible | `edita-1.0.0.rc.8-1.x86_64.rpm` or `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` or `sudo zypper install ./edita-*.rpm` |
| Any other distribution | `Edita-1.0.0-rc.8-x86_64.AppImage` or `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` and open it |

On x86_64 it works on Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. On arm64 it needs Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 or newer. If you had an earlier version, install this one over it: your settings are kept.

## What changes since rc 7

- **Word wrap per document**, like the next Notepad++ release: View › Word wrap changes it for the current document (in both views if it is cloned), the session keeps it, and the preference becomes the one new documents start with. A large file opens without word wrap without taking it away from the others.
- **The Bash Function List** no longer gets lost after a here-document with a quoted delimiter (`<<'EOF'`, `<<"EOF"`).
- **An icon for monitored documents** (View › Monitoring), the same on the tabs, in the Document List and in the palette.
- **The Deep Black theme**, up to date with the Notepad++ one.
- **Edita in the Linux software stores**: with its AppStream metadata, Edita installed from the .deb or .rpm shows up in GNOME Software and KDE Discover with its description and screenshots.
- **Ready for Flatpak**: inside Flatpak, git, language servers, tasks and the terminal use the programs of your system. The Flathub package will come with 1.0.
- **Website**: https://alktrip.github.io/edita/
- **Clearer wording** about what Edita is and how it relates to Notepad++, in the application (Help › About Edita), the README and the store.
