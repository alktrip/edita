**Edita 1.0.0 rc 1**, la primera versión candidata a la 1.0. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The first release candidate of Edita 1.0, a native text editor for Linux inspired by Notepad++. English below.*

Una versión candidata es la 1.0 tal como pensamos publicarla. Si no aparece nada grave, la 1.0.0 será esta misma versión con otro número. Si aparece, habrá una rc 2.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux. Esta versión es solo para Linux.

## Descargar

- `Edita-1.0.0-rc.1-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Si ya tenías una beta, solo sustitúyela: tu configuración se conserva.
- `edita_1.0.0.rc.1_amd64.deb`, para Debian 12 y Ubuntu 22.04 o más nuevo: `sudo apt install ./edita_*_amd64.deb`. Sustituye a la beta que tengas instalada.

## Qué cambia desde la beta 11

**Cambios que vas a notar:**

- **F12 vuelve a funcionar.** F12 tenía dos órdenes a la vez, Post-It e Ir a la definición, y por eso no hacía ninguna. Ahora F12 es **Post-It**, como en Notepad++, e **Ir a la definición** pasa a **Alt+F12**. Los atajos que hayas cambiado tú se conservan.
- **Letras de acceso de los menús.** En un menú, Alt+letra lleva ahora a una sola orden siempre que hay letras libres. Por eso algunas órdenes cambian de letra, sobre todo en Buscar, Ver y Editar. Las más usadas conservan la suya, como **&Reemplazar…** y **Guardar &como…**. En inglés se usan las letras de Notepad++.

**Avisos de versiones nuevas.** Las versiones estables (desde la 1.0.0) buscan actualizaciones cada 15 días y solo avisan de otras estables, nunca de betas ni de versiones candidatas. Las versiones de prueba, como esta, siguen buscando cada día y avisan de todo. Si cambiaste el intervalo a mano, se conserva.

**La API de plugins queda fija para toda la 1.x.** Un plugin compilado para la 1.0 funcionará en cualquier 1.x sin volver a compilarlo: las versiones nuevas solo añaden mensajes. Los detalles están en [docs/plugins.md](https://github.com/alktrip/edita/blob/main/docs/plugins.md#qué-no-cambia-en-edita-1x).

**Detalles:**

- El diálogo para ejecutar una macro varias veces dice «1 vez» y «2 veces» (antes, «1 veces»).
- En el diálogo Buscar, el recuadro «Modo de búsqueda» ya no se estira y las opciones quedan juntas.
- **Ayuda › Acerca de** incluye el enlace a la página del proyecto.
- El manual tiene la captura del diálogo Buscar con sus casillas nuevas, y todas las capturas están al día.

Esta es la versión que más nos interesa que pruebes. Lo nuevo de las betas anteriores está en las notas de la [beta 11](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.11) y la [beta 10](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.10).

## What changes since beta 11

**Changes you will notice:**

- **F12 works again.** F12 had two commands at once, Post-It and Go to Definition, so it did neither. Now F12 is **Post-It**, as in Notepad++, and **Go to Definition** moves to **Alt+F12**. Shortcuts you changed yourself are kept.
- **Menu access keys.** Within a menu, Alt+letter now leads to a single command whenever there are free letters. Some commands therefore get a different letter, mostly in Search, View and Edit. In English the letters follow Notepad++.

**New version notices.** Stable versions (from 1.0.0 on) check for updates every 15 days and only announce other stable versions, never betas or release candidates. Test versions, like this one, still check every day and announce everything. If you changed the interval yourself, it is kept.

**The plugin API is fixed for the whole 1.x series.** A plugin built for 1.0 will work in any 1.x without being rebuilt: new versions only add messages. The details are in [docs/plugins.md](https://github.com/alktrip/edita/blob/main/docs/plugins.md#qué-no-cambia-en-edita-1x) (in Spanish).

**Details:**

- The dialog to run a macro several times says "1 time" and "2 times" (it used to say "1 times").
- In the Find dialog, the "Search Mode" box no longer stretches and its options stay together.
- **Help › About** includes the link to the project page.
- The manual has a screenshot of the Find dialog with its new checkboxes, and all screenshots are up to date.

This is the version we most want you to test. What is new in earlier betas is in the notes of [beta 11](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.11) and [beta 10](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.10).
