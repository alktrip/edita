**Edita 1.0.0 rc 4**, la cuarta versión candidata a la 1.0. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The fourth release candidate of Edita 1.0, a native text editor for Linux inspired by Notepad++. English below.*

Esta versión adelanta a la 1.0 varias funciones que estaban planeadas para la 1.1, así que pasan por una versión candidata. Si no aparece nada grave, la 1.0.0 será esta misma versión con otro número.

## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.4_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0.rc.4-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-rc.4-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si ya tenías una versión anterior, instala esta encima: tu configuración se conserva.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux.

## Qué cambia desde la rc 3

**Herramientas de CSV** (Editar › CSV). En los archivos `.csv`, `.tsv` y `.psv`, cada columna se pinta de un color. Puedes alinear las columnas con espacios (y quitarlos) y ordenar las filas por la columna del cursor, de números o de texto, con el encabezado fijo.

**JSON y YAML** (Editar › JSON/YAML). Validar (el cursor va al error, con la línea y la columna), formatear y compactar JSON sin cambiar el orden de las claves ni los números, convertir entre JSON y YAML, y copiar la ruta del valor del cursor (`$.services.web.ports[1]`).

**Panel TODO** (Ver › TODO). Los comentarios `TODO`, `FIXME`, `HACK`, `XXX`, `BUG` y `NOTE` del documento o de todas las carpetas de trabajo, con doble clic a la línea.

**Historial de Git** (Ver › Git, pestaña Historial). Los últimos commits del repositorio o del archivo actual, los archivos de cada uno y su diff.

**Filtro en el explorador de carpetas.** Escribe palabras o comodines (`*.cpp *.h`) y el árbol muestra solo lo que coincide.

**F1 contextual.** En un diálogo o un panel, F1 abre el apartado del manual que lo explica.

**Los paneles recuerdan su sitio**, su tamaño y con qué otros comparten pestañas, también los de los plugins.

**Acerca de Edita, renovado.** La versión con la arquitectura y la forma de instalación, si hay una versión nueva, enlaces útiles, los componentes que usa Edita con sus licencias y un botón para copiar la información de la versión en un reporte.

**Plugins ya compilados para arm64.** En un equipo ARM, el administrador de plugins instala los plugins del catálogo ya compilados, como en un PC.

**Más calidad.** Todas las pruebas se ejecutan también con AddressSanitizer y UndefinedBehaviorSanitizer, que encontraron y permitieron corregir dos casos de comportamiento indefinido (uno al cerrar un editor con fragmentos y otro en la detección de codificación heredada de Notepad++).

Lo nuevo de la rc 3 (editor hexadecimal, detector de secretos, FTP y SFTP) está en sus [notas](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.3).

## What changes since rc 3

**CSV tools** (Edit › CSV). In `.csv`, `.tsv` and `.psv` files, every column is painted in a color. You can align the columns with spaces (and remove them) and sort the rows by the column of the caret, as numbers or text, with the header kept at the top.

**JSON and YAML** (Edit › JSON/YAML). Validate (the caret goes to the error, with its line and column), format and compact JSON without changing the order of the keys or the numbers, convert between JSON and YAML, and copy the path of the value at the caret (`$.services.web.ports[1]`).

**TODO panel** (View › TODO). The `TODO`, `FIXME`, `HACK`, `XXX`, `BUG` and `NOTE` comments of the document or of all the workspace folders, with a double click to the line.

**Git history** (View › Git, History tab). The last commits of the repository or of the current file, the files of each one and their diff.

**Filter in the folder explorer.** Type words or wildcards (`*.cpp *.h`) and the tree shows only what matches.

**Contextual F1.** In a dialog or a panel, F1 opens the section of the manual that explains it.

**Panels remember their place**, their size and which panels they share tabs with, plugin panels too.

**A new About Edita.** The version with the architecture and how it was installed, whether there is a newer version, useful links, the components Edita uses with their licenses, and a button to copy the version information into a report.

**Prebuilt plugins for arm64.** On an ARM computer, the Plugins Admin installs the catalog plugins prebuilt, as on a PC.

**Better quality.** Every test also runs with AddressSanitizer and UndefinedBehaviorSanitizer, which found two cases of undefined behavior that are now fixed (one when closing an editor with snippets, one in the encoding detection inherited from Notepad++).

What was new in rc 3 (hex editor, secret scanner, FTP and SFTP) is in its [notes](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.3).
