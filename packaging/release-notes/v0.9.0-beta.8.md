**Edita 0.9.0 beta 8**, la octava beta pública. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The eighth public beta of Edita, a native text editor for Linux inspired by Notepad++. English below.*

> **macOS:** la versión para macOS se retomará cuando haya una versión estable para Linux. Esta beta es solo para Linux.

## Descargar

`Edita-0.9.0-beta.8-x86_64.AppImage`, para Linux x86_64: Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. Dale permiso de ejecución (`chmod +x`) y ábrelo. Si ya tenías una beta anterior, solo sustitúyela: tu configuración se conserva.

## Qué cambia desde la beta 7

- **Abrir o mover un documento a otra ventana:** **Ver › Abrir en otra ventana** y **Mover a otra ventana**, también en el clic derecho sobre la pestaña. La ventana nueva abre el archivo en la misma línea y con el mismo lenguaje. Al moverlo se cierra aquí. Funciona con documentos guardados.
- **Elegir el lenguaje desde la terminal:** la opción `-l` (o `--language`), como en Notepad++. Por ejemplo, `edita -l python notas.txt`.
- **Editar › Pegado especial:**
  - **Pegar contenido HTML** y **Pegar contenido RTF** pegan el código de lo que copiaste de una página web o de un procesador de textos.
  - **Copiar, cortar y pegar contenido binario** conservan los caracteres NUL.
- **El menú de las pestañas se personaliza** con `tabContextMenu.xml`, como en Notepad++. Para crearlo y abrirlo: **Configuración › Editar el menú de las pestañas**. Si borras el archivo, vuelve el menú de siempre.

Lo nuevo de las betas anteriores está en las notas de la [beta 7](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.7) y de la [beta 6](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.6).

## Es una beta

Úsala para trabajar, pero guarda copias de lo importante. Para reportar un problema: **Ayuda › Reportar un problema…**. La guía [PROBAR.md](https://github.com/alktrip/edita/blob/main/PROBAR.md) dice qué probar.

## Download

`Edita-0.9.0-beta.8-x86_64.AppImage`, for Linux x86_64: Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. Make it executable (`chmod +x`) and open it. If you had an earlier beta, just replace it: your settings are kept.

## What changes since beta 7

- **Open or move a document to another window:** **View › Open in New Instance** and **Move to New Instance**, also in the right-click menu of the tab. The new window opens the file at the same line and with the same language. Moving it closes it here. It works with saved documents.
- **Choose the language from the terminal:** the `-l` (or `--language`) option, as in Notepad++. For example, `edita -l python notes.txt`.
- **Edit › Paste Special:**
  - **Paste HTML Content** and **Paste RTF Content** paste the code of what you copied from a web page or a word processor.
  - **Copy, Cut and Paste Binary Content** keep the NUL characters.
- **The tab menu can be customized** with `tabContextMenu.xml`, as in Notepad++. To create and open it: **Settings › Edit Tab ContextMenu**. If you delete the file, the usual menu comes back.

What is new in earlier betas is in the notes of [beta 7](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.7) and [beta 6](https://github.com/alktrip/edita/releases/tag/v0.9.0-beta.6).

## It is a beta

Use it for your work, but keep copies of what matters. To report a problem: **Help › Report a Problem…**. The [testing guide](https://github.com/alktrip/edita/blob/main/PROBAR.md#testing-edita-090-beta) says what to test.
