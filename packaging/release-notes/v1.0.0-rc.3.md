**Edita 1.0.0 rc 3**, la tercera versión candidata a la 1.0. Edita es un editor de texto nativo para Linux inspirado en Notepad++ (Qt 6, Scintilla 5, GPL v3).

*The third release candidate of Edita 1.0, a native text editor for Linux inspired by Notepad++. English below.*

Esta versión trae plugins nuevos que no estaban en la rc 2, así que pasan por una versión candidata antes de la 1.0. Si no aparece nada grave, la 1.0.0 será esta misma versión con otro número.

## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0.rc.3_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0.rc.3-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-rc.3-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si ya tenías una versión anterior, instala esta encima: tu configuración se conserva.

> **macOS:** la versión para macOS se retomará después de la 1.0 para Linux.

## Qué cambia desde la rc 2

**Editor hexadecimal** (Plugins › Hex Editor, **Ctrl+Alt+Mayús+H**, como en Notepad++). Viene incluido. Muestra y edita los bytes de cualquier archivo, también binarios: en hexadecimal o ASCII, sobrescribiendo o insertando, con deshacer y rehacer. Busca bytes o texto, va a una posición (`0x1F`) y muestra el valor del cursor como entero, flotante o carácter. Abre archivos de hasta 512 MB.

**Detector de secretos** (Plugins › Secret Scanner). Viene incluido. Subraya en rojo las claves de API, tokens, claves privadas y contraseñas que escribes en tus archivos (GitHub, AWS, OpenAI, Anthropic, Stripe y más), los lista en un panel y analiza el proyecto completo. Antes de un commit desde el panel Git, avisa si lo que vas a confirmar contiene alguno.

**FTP y SFTP**, en el catálogo de plugins (Plugins › Administrador de plugins, **FTP and SFTP**). Hace lo que NppFTP: guardas tus servidores, exploras sus carpetas por SFTP, FTP, FTPES o FTPS, abres un archivo con doble clic y se sube solo al guardarlo. Usa `ssh`, `sftp` y `curl` del sistema, con tus claves y tu configuración de `~/.ssh`. Las contraseñas no se guardan en el disco. También funciona con la rc 2.

**Más plugins de Notepad++ en el catálogo:** JSON Viewer, Npp Converter y NppExport, además de MIME Tools 3.2 y SQL Column Highlighter 1.0.4. El catálogo ya tiene 23 plugins, y sus descripciones aparecen en el idioma de la interfaz.

Lo nuevo de la rc 2 (historial local, tareas del proyecto, Git desde el margen, paquetes .rpm y arm64) está en sus [notas](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.2).

## Probar y reportar

Nos interesa sobre todo cómo te van los tres plugins nuevos. Para reportar un problema: **Ayuda › Reportar un problema…**. La guía [PROBAR.md](https://github.com/alktrip/edita/blob/main/PROBAR.md) dice qué probar. Guarda copias de lo importante, como con cualquier versión de prueba.

En arm64 el catálogo de plugins todavía no trae plugins ya compilados: el administrador ofrece compilarlos en tu equipo (hacen falta cmake y un compilador de C++), y eso aún no se ha probado bien en ARM. Si lo intentas, cuéntanos cómo te fue.

| System | File | Install |

| Fedora, openSUSE and compatible | `edita-1.0.0.rc.3-1.x86_64.rpm` or `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` or `sudo zypper install ./edita-*.rpm` |

On x86_64 it works on Ubuntu 22.04 or newer, Debian 12, Fedora 36 and later. On arm64 it needs Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 or newer. If you had an earlier version, install this one over it: your settings are kept.

> **macOS:** the macOS version will resume after 1.0 for Linux.

## What changes since rc 2

**Hex Editor** (Plugins › Hex Editor, **Ctrl+Alt+Shift+H**, as in Notepad++). Bundled. It shows and edits the bytes of any file, binaries included: in hexadecimal or ASCII, overwriting or inserting, with undo and redo. It finds bytes or text, goes to an offset (`0x1F`) and shows the value at the cursor as an integer, a float or a character. It opens files up to 512 MB.

**Secret Scanner** (Plugins › Secret Scanner). Bundled. It underlines in red the API keys, tokens, private keys and passwords you write in your files (GitHub, AWS, OpenAI, Anthropic, Stripe and more), lists them in a panel and scans the whole project. Before a commit from the Git panel, it warns you if what you are committing contains one.

**FTP and SFTP**, in the plugin catalog (Plugins › Plugins Admin, **FTP and SFTP**). It does what NppFTP does: save your servers, browse their folders over SFTP, FTP, FTPES or FTPS, open a file with a double click and it is uploaded when you save it. It uses the system's `ssh`, `sftp` and `curl`, with your keys and your `~/.ssh` configuration. Passwords are not saved to disk. It also works with rc 2.

**More Notepad++ plugins in the catalog:** JSON Viewer, Npp Converter and NppExport, plus MIME Tools 3.2 and SQL Column Highlighter 1.0.4. The catalog now has 23 plugins, and their descriptions appear in the language of the interface.

What was new in rc 2 (local history, project tasks, Git from the margin, .rpm and arm64 packages) is in its [notes](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.2).

## Testing and reporting

We would especially like to hear how the three new plugins work for you. To report a problem: **Help › Report a Problem…**. The [testing guide](https://github.com/alktrip/edita/blob/main/PROBAR.md#testing-edita) says what to test. Keep copies of what matters, as with any test version.

On arm64 the plugin catalog has no prebuilt plugins yet: the Plugins Admin offers to build them on your computer (cmake and a C++ compiler are needed), and that has not been well tested on ARM yet. If you try it, tell us how it went.
