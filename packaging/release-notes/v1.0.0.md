**Edita 1.0.0**, la primera versión estable. Edita es un editor de texto y código nativo para Linux para quien conoce Notepad++: los mismos menús, atajos, modos de búsqueda, macros, sesiones, temas y archivos de configuración, sobre el mismo motor de edición, con los plugins de Notepad++ y lo que hoy espera quien programa: servidores de lenguaje, Git y una terminal. Sitio web: https://alktrip.github.io/edita/es/

*Edita 1.0.0, the first stable release: a native Linux text and code editor with the Notepad++ workflow, its plugins, and language servers, Git and a terminal. English below. Website: https://alktrip.github.io/edita/*

## Descargar

Hay versiones para PC (**x86_64**) y para ARM de 64 bits (**arm64**: Raspberry Pi 4 y 5, portátiles y servidores ARM). `uname -m` dice cuál es tu equipo.

| Sistema | Archivo | Instalar |
|---|---|---|
| Debian, Ubuntu, Linux Mint | `edita_1.0.0_amd64.deb` o `_arm64.deb` | `sudo apt install ./edita_*.deb` |
| Fedora, openSUSE y compatibles | `edita-1.0.0-1.x86_64.rpm` o `.aarch64.rpm` | `sudo dnf install ./edita-*.rpm` o `sudo zypper install ./edita-*.rpm` |
| Cualquier otra distribución | `Edita-1.0.0-x86_64.AppImage` o `-aarch64.AppImage` | `chmod +x Edita-*.AppImage` y ábrelo |
| Flatpak | pronto en Flathub | |

En x86_64 funciona en Ubuntu 22.04 o más nuevo, Debian 12, Fedora 36 y posteriores. En arm64 hace falta Ubuntu 24.04, Debian 13, Raspberry Pi OS 13 (trixie), Fedora 40 o más nuevos. Si tenías una versión de prueba (beta o rc), instala esta encima: tu configuración se conserva.

## Qué es Edita

- **Lo de Notepad++:**
  - pestañas, dos vistas y clones, sesiones;
  - buscar y reemplazar (normal, extendido y expresiones regulares, en archivos y carpetas, Marcar);
  - macros, editor de columnas, edición múltiple;
  - mapa del documento, lista de funciones, Carpeta como espacio de trabajo;
  - lenguajes definidos por el usuario, Configurador de estilos, 30 temas y 95 lenguajes;
  - los archivos `config.xml`, `langs.xml`, `stylers.xml` y `shortcuts.xml` de Notepad++.
- **Plugins de Notepad++** compilados para Linux, en un catálogo firmado para x86_64 y arm64: XML Tools, JSON Viewer, MIME Tools, Npp Converter y más. Incluidos: Python Script, MarkdownViewer++, un editor hexadecimal y un detector de secretos.
- **Para programar:**
  - servidores de lenguaje (LSP);
  - Git (los cambios en el margen, preparar un bloque, panel de commit, historial y blame);
  - terminal integrada y tareas del proyecto;
  - paleta de órdenes, comparar archivos e historial local;
  - herramientas de CSV, JSON y YAML, y panel TODO.
- **Manual incluido** (F1 abre el apartado del diálogo o panel en el que estás) e interfaz en español e inglés.

## Qué cambia desde la rc 7

- **Ajuste de línea por documento**, como la próxima versión de Notepad++: Ver › Ajuste de línea cambia el del documento actual, la sesión lo guarda y la preferencia es la de los documentos nuevos.
- **La lista de funciones de Bash** ya no se pierde después de un here-document con el delimitador entre comillas (`<<'EOF'`).
- **Un icono para los documentos en seguimiento** (Ver › Seguimiento), en las pestañas y en la Lista de documentos.
- **El tema Deep Black**, al día con el de Notepad++.
- **Edita en las tiendas de Linux**: con sus metadatos de AppStream, Edita instalada desde el .deb o el .rpm aparece en GNOME Software y KDE Discover con su descripción y sus capturas. La versión para Flathub está lista y se publicará allí en los próximos días.

Lo de cada versión candidata está en sus notas: [rc 7](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.7), [rc 6](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.6), [rc 4](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).

## What Edita is

- **The Notepad++ core:**
  - tabs, two views and clones, sessions;
  - find and replace (normal, extended and regular expressions, in files and folders, Mark);
  - macros, column editor, multi-editing;
  - Document Map, Function List, Folder as Workspace;
  - User Defined Languages, Style Configurator, 30 themes and 95 languages;
  - the Notepad++ `config.xml`, `langs.xml`, `stylers.xml` and `shortcuts.xml` files.
- **Notepad++ plugins** compiled for Linux, in a signed catalog for x86_64 and arm64: XML Tools, JSON Viewer, MIME Tools, Npp Converter and more. Included: Python Script, MarkdownViewer++, a hex editor and a secret scanner.
- **For developers:**
  - language servers (LSP);
  - Git (changes in the margin, stage a block, commit panel, history and blame);
  - an integrated terminal and project tasks;
  - command palette, file comparison and local history;
  - CSV, JSON and YAML tools, and a TODO panel.
- **A built-in manual** (F1 opens the section of the dialog or panel you are in) and an interface in English and Spanish.

## What changes since rc 7

- **Word wrap per document**, like the next Notepad++ release: View › Word wrap changes it for the current document, the session keeps it, and the preference is the one new documents start with.
- **The Bash Function List** no longer gets lost after a here-document with a quoted delimiter (`<<'EOF'`).
- **An icon for monitored documents** (View › Monitoring), on the tabs and in the Document List.
- **The Deep Black theme**, up to date with the Notepad++ one.
- **Edita in the Linux software stores**: with its AppStream metadata, Edita installed from the .deb or .rpm shows up in GNOME Software and KDE Discover with its description and screenshots. The Flathub version is ready and will be published there in the coming days.

What each release candidate brought is in its notes: [rc 7](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.7), [rc 6](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.6), [rc 4](https://github.com/alktrip/edita/releases/tag/v1.0.0-rc.4).
